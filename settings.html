Device Connection

Setup: Lovense Remote
PC
  1. Install Lovense Remote on your PC and pair your toy
  2. Keep Lovense Remote running in the background
  3. Click "Connect" below and allow the third-party connection in the app
Mobile
  1. Install Lovense Remote (iOS / Android) and pair your toy
  2. Put your phone and PC on the same WiFi network
  3. In Lovense Remote: Discover → Game Mode → Enable LAN
  4. Enter the IP and port it shows below, then click "Connect"
Needs the server plugin. See the README.
PC: 127.0.0.1 and 30010. Mobile: the IP from Game Mode (e.g. 192.168.1.44) and usually 20010.
Setup: Intiface Central
  1. Install Intiface Central and press the big start button
  2. Turn your toy on. Intiface finds it over Bluetooth (no Lovense app needed)
  3. Click "Connect" below
Works with Lovense and most other brands. No server plugin needed.

    How patterns are chosen

    Pick a fast, cheap model. It's separate from your chat model and only sees the finished message plus a short list of moods.
    Raise this if a reasoning model runs out of room before answering.
    Picker prompt The mood list is added after this automatically. The reply must be JSON with "mood" and "energy".
    Added to the system prompt along with the command syntax. With several toys connected, the AI can target one using device="name".

    Timing

    Swiping, editing or regenerating restarts the countdown, so only the message you keep sets the toys.
    React to
    Automatic picks only use a pattern whose one pass is inside this range. It still loops if looping is on. If you set a minimum above the maximum, the other side moves to match. "Try a pattern" ignores this. When a toy is connected, skip patterns that spend real time on a feature it doesn't have, like a second motor answering the first, or thrust and rotation doing their own thing. Patterns that only vibrate, or that copy the vibration onto other features, stay. Nothing is hidden until a toy is connected. "Try a pattern" follows this; turn it off to play those by hand.
    For toys with an air pump (Max, Max 2). The pump plays the same shape as the pattern, just this many times slower, so it holds a squeeze instead of chasing every beat. The vibration keeps its normal speed.

    Moods

    Switched-off moods are never picked (and never sent to the picker model).
